## 🔮 Featured Plugin

### 🛡️ Crystal Guard
An all-in-one combat and performance engine engineered specifically for competitive CPvP (Crystal PvP).

* **Built-in Combat AntiCheat** — Protects against packet exploits, illegal placement speeds, and combat cheats.
* **LagShield Engine** — Optimizes entity spawning and explosion physics to keep server TPS at 20.0 during intense fights.
* **Crystal & Anchor Optimization** — Zero-lag End Crystal placements and fast Respawn Anchor interactions.
* **Fast XP & Damage Scaling** — Smooth Experience Bottle velocity and fully customizable crystal damage multipliers.

## 📥 Installation & Setup

1. Head over to the **Releases** tab or our official site to download the latest `.jar` file (e.g., `Crystalguard-1.0.0.jar`).
2. Drop the downloaded file into your server's `/plugins` directory.
3. Restart your server to generate default configurations.
